# subtitle-tts-tool-archive

Bản lưu giao diện trình duyệt xử lý phụ đề và đọc văn bản. Kiểm tra ngoại tuyến được ghi riêng; chưa xác minh API trả phí, tín dụng, chất lượng giọng hoặc tính năng video.

Mở `app/index.html` hoặc phục vụ thư mục `app` bằng một HTTP server cục bộ. Nhập API key của chính bạn khi cần dùng dịch vụ. API thật và tác vụ trả phí chưa được chạy trong lần kiểm kê. Không có API key hoặc audio người dùng trong repository.

Xem [ARCHIVE_NOTES.md](ARCHIVE_NOTES.md), [SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) và [VALIDATION.md](VALIDATION.md) để biết phạm vi và kết quả kiểm tra.
